    操作
    
    
    
      
    操作動作キー
    
      
    逐次 / パイプライン実行方式を切り替えます（切り替えるとリセット）。逐次は 1 ステップ = 1 命令、パイプラインは 1 ステップ = 1 クロックです
    
      
    ⟲ リセットレジスタとメモリを初期値に戻し、PC を開始アドレスにしますF8
    
      
    ◀1 ステップ（または 1 回の書き換え）戻ります
    
      
    ステップ1 命令（パイプラインでは 1 クロック）実行しますF10
    
      
    ▶ 実行 / ■ 停止停止条件（終了・ブレークポイント・最大ステップ数）まで実行しますF9
    
      
    ⚙ 設定遅延分岐・ロード直後の動作と、実行の速さ・最大ステップ数を設定します
    
    
    
    
    値の書き換え：「レジスタ」「メモリ」画面で値をクリックして入力します（メモリは Enter で次の番地へ）。クロック 0 で書き換えると初期値として保存され、リセット後も残ります。実行の途中で書き換えると今の値だけが変わり、◀ で取り消せます。$sp と $gp の初期値は MARS / SPIM と同じ 7FFFEFFC / 10008000 です。
    
    
    機械語の画面：行をクリックするとソースの該当行へ移動し、左端の ● をクリックするとブレークポイントを設定します。
    
    
    画面の切り替え：Alt+1 機械語 / Alt+2 レジスタ / Alt+3 メモリ / Alt+4 パイプライン / Alt+5 履歴 / Alt+6 出力 / Alt+7 ログ
    
    
    履歴：「パイプライン図」は命令ごとに各クロックのステージを示します（ID ストール はロード結果待ちの停止、IF 破棄 は分岐成立で捨てた命令、←EX などはフォワーディング元のステージ）。「値の変化」はレジスタ・メモリの値をクロックごとに並べます。
    

    
    実行方式の設定
    
    
    
      
    設定動作
    
      
    遅延分岐オン：分岐・ジャンプの直後の 1 命令（遅延スロット）を常に実行し、JAL は $ra = PC+8。オフ（既定）：遅延スロットなし。パイプラインでは分岐成立時に、すでにフェッチした 1 命令をフラッシュし、JAL は $ra = PC+4
    
      
    ロード直後: ストール（既定）パイプラインで、ロードの結果を直後の命令が使うときは 1 クロック停止（バブルを挿入）してから受け取る
    
      
    ロード直後: 遅延ロードMIPS I と同じく停止せず、直後の命令は古い値を読む（ログに警告を出します）
    
    
    
    
    パイプラインは IF / ID / EX / MEM / WB の 5 段で、分岐は ID で判定し、EX・MEM・WB からのフォワーディングを行います。メモリはビッグエンディアンです。
    
    
    ADD・ADDI・SUB で符号付きオーバーフローが起きると例外として停止します（結果は書き込まれません）。例外を起こさない ADDU・ADDIU・SUBU も使えます。
    

    
    入力補助（プルダウンで入力）
    
    
    エディタ上部の「▾ 入力補助」をクリックすると開閉します。① 形式（R / I / J / 擬似）を選び、② 命令を選ぶと必要なオペランドの欄が出るので、レジスタをプルダウンで選び、数値や飛び先を入力して「追加」（Enter）を押すと、エディタのカーソル行の次に 1 行追加されます。
      「置換」でカーソル行を置き換え、「行を読込」でカーソル行の命令をパネルに読み込んで編集できます。飛び先の欄では、プログラム中のラベルを候補から選べます。Ctrl+Z で元に戻せます。
    

    
    命令
    
    
    
      
    形式命令書式
    
      
    RADD ADDU SUB SUBU AND OR XOR NOR SLT SLTUADD rd, rs, rt
    
      
    RSLL SRL SRA / SLLV SRLV SRAVSLL rd, rt, shamt SLLV rd, rt, rs
    
      
    RMULT MULTU DIV DIVU / MFHI MFLO / MTHI MTLOMULT rs, rt MFLO rd MTHI rs
    
      
    RJR JALRJR rs JALR rs JALR rd, rs
    
      
    RSYSCALL BREAKSYSCALL BREAK
    
      
    IADDI ADDIU SLTI SLTIU ANDI ORI XORIADDI rt, rs, imm
    
      
    ILUILUI rt, imm
    
      
    ILW LH LHU LB LBU / SW SH SBLW rt, offset(rs) LW rt, ラベル LW rt, ラベル+4 LW rt, ラベル(rs)
    
      
    IBEQ BNEBEQ rs, rt, 飛び先
    
      
    IBLEZ BGTZ BLTZ BGEZ BLTZAL BGEZALBLEZ rs, 飛び先（rs と 0 を比較。…AL は $ra に戻り番地）
    
      
    JJ JALJ 飛び先
    
      
    擬似NOP LI LA MOVE NOT NEG NEGU MUL DIV DIVULI rd, n LA rd, ラベル MOVE rd, rs NOT rd, rs MUL rd, rs, rt
    
      
    擬似B BEQZ BNEZ / BLT BGE BGT BLE / BLTU BGEU BGTU BLEUB 飛び先 BEQZ rs, 飛び先 BLT rs, rt, 飛び先
    
    
    
    
    飛び先：ラベル（LOOP）、絶対アドレス（0x00400010）、条件分岐のみ符号付きオフセット（+3、-2）。
    
    
    レジスタ：$0〜$31 または $zero $at $v0 $a0 $t0 $s0 $sp $ra など。数値：10進・0x16進・0b2進・文字（'A'、'\n'）。擬似命令の展開には $at（$1）を使います。
    

    
    ディレクティブ（データの定義）
    
    
    
      
    ディレクティブ動作
    
      
    .text / .data [番地]以降を命令（既定 0x00400000〜）/ データ（既定 0x10010000〜）として配置
    
      
    .word .half .byte4 / 2 / 1 バイトの値を並べる（例: .word 1, 2, LABEL）。.word と .half は境界に自動でそろえます
    
      
    .ascii "…" / .asciiz "…"文字列（UTF-8）。.asciiz は末尾に 0 を付ける。\n \t \0 \" \\ が使えます
    
      
    .space nn バイトの領域を確保（値は 0）
    
      
    .align n2n バイト境界にそろえる（n = 0〜3）
    
      
    .globl書いても動作に影響しません
    
    
    
    
            .data
ARRAY:  .word   3, 1, 4, 1, 5
MSG:    .asciiz "合計 = "
        .text
MAIN:   LA      $a0, MSG
        LI      $v0, 4
        SYSCALL                 # 文字列を出力
        LW      $t0, ARRAY+4    # $t0 = 1
    

    
    システムコール（SYSCALL）
    
    
    $v0 にサービス番号、$a0 に引数を入れて SYSCALL を実行します。出力は「出力」画面に表示されます。
    
    
    
      
    $v0動作
    
      
    1$a0 を符号付き 10 進で出力
    
      
    4$a0 の番地から 0 のバイトまでを文字列（UTF-8）として出力
    
      
    10プログラムを終了
    
      
    11$a0 の下位 8 ビットを文字として出力
    
      
    17$a0 を終了コードとしてプログラムを終了
    
      
    34$a0 を 16 進（0x 付き 8 桁）で出力
    
    
    
    
    BREAK を実行すると、その場で停止します。
